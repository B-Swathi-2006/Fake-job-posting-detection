DATASET

EMSCAD

The supplied Employment Scam Aegean Dataset is used to train and evaluate the traditional model. Its verified target column is fraudulent.

Available fields

The CSV includes title, location, department, salary range, company profile, description, requirements, benefits, employment type, experience, education, industry, function, and additional binary posting attributes.

Pipeline

All available non-target fields → missing-value handling → duplicate removal → text cleaning → TF-IDF unigrams and bigrams → Random Forest → measured probability.

The training script uses a stratified held-out split and reports an error rather than guessing an unknown schema.
